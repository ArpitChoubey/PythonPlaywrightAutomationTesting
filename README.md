# 🚀 Python Playwright Automation Testing

A comprehensive **Playwright Automation Repository** built using **Python** that demonstrates modern web automation techniques, browser interactions, UI validations, debugging capabilities, and real-world automation scenarios.

Unlike repositories that only automate login functionality, this project covers a broad range of practical automation use cases commonly encountered in enterprise web applications.

The repository uses the **Osprey e-commerce website** for demonstrating realistic user journeys and browser automation.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/ArpitChoubey/PythonPlaywrightAutomationTesting.git
```

---

## Navigate

```bash
cd PythonPlaywrightAutomationTesting
```

---

## Install Dependencies

```bash
pip install playwright
```

---

## Install Browsers

```bash
playwright install
```

---

## Execute Test

```bash
python FirstTest_Playwright.py
```

Run any example:

```bash
python Test_FileUpload.py
```

or

```bash
python Test_DynamicTable.py
```
